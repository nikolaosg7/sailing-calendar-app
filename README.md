## 📖 Περιγραφή Project
Το **Sailing Calendar Pro** είναι ένα εργαλείο εξαγωγής του Αγωνιστικού Ημερολογίου Ιστιοπλοΐας (ΕΑΘ/ΕΙΟ). Αναπτύχθηκε στα πλαίσια πανεπιστημιακής εργασίας (ΕΑΠ) και επιτρέπει στους χρήστες να βλέπουν, να φιλτράρουν και να κατεβάζουν τους αγώνες σε μορφή `.ics` (iCalendar) για άμεση εισαγωγή σε πλατφόρμες όπως το Google Calendar και το Outlook.

## ✨ Δυνατότητες
* **Live Web Scraping:** Αντλεί τα δεδομένα σε πραγματικό χρόνο από την επίσημη πηγή της Ομοσπονδίας (XML).
* **Διαδραστικό UI:** Μοντέρνο γραφικό περιβάλλον με χρήση της βιβλιοθήκης `Streamlit`.
* **Φίλτρα Αναζήτησης:** Δυνατότητα φιλτραρίσματος ανά Περιφέρεια, Όμιλο ή όνομα Αγώνα.
* **Εξαγωγή iCalendar:** Αυτόματη δημιουργία δομημένου αρχείου `.ics`.
