# ⛵ Sailing Calendar Pro

## 📖 Περιγραφή Project
Το Sailing Calendar Pro είναι ένα εργαλείο για το Αγωνιστικό Ημερολόγιο Ιστιοπλοΐας (ΕΑΘ/ΕΙΟ). Αναπτύχθηκε για την ομαδική εργασία στην ενότητα ΠΛΗΠΡΟ του ΕΑΠ.

## ✨ Δυνατότητες
* **Live Web Scraping:** Δεδομένα σε πραγματικό χρόνο.
* **Διαδραστικό UI:** Γραφικό περιβάλλον με Streamlit.
* **Εξαγωγή iCalendar:** Αρχεία .ics για Google Calendar.

## 🚀 Εγκατάσταση
1. `pip install streamlit pandas requests beautifulsoup4 icalendar lxml`
2. `streamlit run interface.py`
