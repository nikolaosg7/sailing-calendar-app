Γεια σας! Αυτό είναι το repository για την ομαδική εργασία της ΠΛΗΠΡΟ του ΕΑΠ. Φτιάξαμε μια διαδραστική web εφαρμογή με Python η οποία λειτουργεί ως ένα δυναμικό, ζωντανό ημερολόγιο για τους ιστιοπλοϊκούς αγώνες ανοιχτής θαλάσσης του 2026.

Δεν χρησιμοποιήσαμε απλά ένα έτοιμο, στατικό αρχείο. Η εφαρμογή συνδέεται απευθείας στην πηγή, τραβάει τα δεδομένα, τα οργανώνει σε δομές Pandas DataFrame, τα καθαρίζει και τα παρουσιάζει σε ένα σύγχρονο UI.

---

## 💡 Τι υλοποιήσαμε (Βασικά Χαρακτηριστικά)

- **Live XML Scraping & Pandas:** Ανάκτηση του προγράμματος μέσω `requests` και δομημένη ανάλυση με `xml.etree.ElementTree`. Στη συνέχεια, τα δεδομένα περνάνε σε **Pandas DataFrames** για γρήγορο φιλτράρισμα και διαχείριση.
- **Custom UI (CSS Grid):** Παρακάμψαμε το default styling του Streamlit γράφοντας custom CSS. Χρησιμοποιήσαμε `display: grid` για να εξασφαλίσουμε απόλυτη στοίχιση στον πίνακα των αγώνων, χωρίς να κόβονται μεγάλα κείμενα (όπως οι ονομασίες των ομίλων).
- **Έξυπνα Φίλτρα & Datetime:** Συγκρίνουμε τις ημερομηνίες των αγώνων με το `datetime.now()` ώστε να κρύβουμε αυτόματα τους αγώνες του παρελθόντος. Διαθέτει επίσης δυναμική αναζήτηση κειμένου και φιλτράρισμα ανά περιφέρεια.
- **Εξαγωγή `.ICS`:** Λειτουργία αυτόματης δημιουργίας iCalendar αρχείου για απευθείας προσθήκη των αγώνων στο Google Calendar ή το Outlook.

## 🚀 Οδηγίες Εκτέλεσης (2 Τρόποι)

### Τρόπος 1: Τοπικά μέσω Python (Προτείνεται)
Αν θέλετε να δείτε τον κώδικα να τρέχει στο δικό σας περιβάλλον, ανοίξτε το τερματικό (π.χ. PowerShell) και ακολουθήστε τα βήματα:

1. **Κλωνοποίηση του κώδικα:**
   ```powershell
   git clone [https://github.com/nikolaosg7/sailing-calendar-app.git](https://github.com/nikolaosg7/sailing-calendar-app.git)
   cd sailing-calendar-app

2. **Δημιουργία Virtual Environment & Ενεργοποίηση:**  
    py -m venv .venv
    .\.venv\Scripts\activate

3. **Εγκατάσταση Βιβλιοθηκών:**
    py -m pip install -r requirements.txt

3. **Εκκίνηση:**
    py -m streamlit run interface.py


📌 Σημείωση για την Αξιολόγηση
Δόθηκε ιδιαίτερη έμφαση στην ευρωστία (error handling) του κώδικα. Το αρχικό XML της ΕΑΘ παρουσιάζει σημαντικές ασυνέπειες στη δομή του (π.χ. το όνομα του διοργανωτή Ομίλου εμφανίζεται πότε ως tag, πότε ως attribute και πότε σε διαφορετικά επίπεδα βάθους).

Για να διασφαλίσουμε την πληρότητα της λύσης και να μην έχουμε κενά δεδομένα, γράψαμε "επιθετικές" ρουτίνες αναζήτησης (recursive loops) στον parser που ψάχνουν κάθε πιθανή θέση στο δέντρο του XML μέχρι να εντοπίσουν τον όμιλο και τη διαδρομή.

### Τρόπος 2: Αυτόνομο Εκτελέσιμο (.exe)
Για τη μέγιστη διευκόλυνση κατά την αξιολόγηση, έχουμε μετατρέψει την εφαρμογή σε ένα αυτόνομο εκτελέσιμο αρχείο χρησιμοποιώντας το **PyInstaller** (με τη μέθοδο `--onefile`). 

Μπορείτε απλά να κάνετε διπλό κλικ στο αρχείο `SailingCalendar2026.exe` που βρίσκεται στον φάκελο `dist` του παραδοτέου. Δεν απαιτείται εγκατάσταση της Python ή άλλων βιβλιοθηκών. *(Σημείωση: Την πρώτη φορά που θα εκτελεστεί, ενδέχεται να χρειαστούν 10-15 δευτερόλεπτα για να αποσυμπιεστούν τα αρχεία στη μνήμη και να φορτώσει ο τοπικός server στο παρασκήνιο).*

Για λόγους διαφάνειας, ο κώδικας-γέφυρα (wrapper) βρίσκεται στο αρχείο `app_run.py` και η εντολή μεταγλώττισης που χρησιμοποιήσαμε ήταν η εξής:
`py -m PyInstaller --noconfirm --onefile --windowed --add-data "interface.py;." --copy-metadata streamlit --collect-all streamlit --hidden-import=icalendar app_run.py`
